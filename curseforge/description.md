# Dragon Maid Companion — NeoForge 1.21.1 社区移植版

> **非官方社区移植**
> 原作者：**别思丶**
> 原 mod / 出处：Dragon Maid Companion（1.20.1 Forge）
> 本移植仓库：https://github.com/bierangas26-cyber/dragonmaid-neoforge

## 说明

这是一个**由 AI 做的粗略移植**，把 *Dragon Maid Companion* 从 1.20.1 Forge 迁移到 **Minecraft 1.21.1 / NeoForge**。

- 免费发布，仅供交流使用
- 移植过程中打了大量补丁，**难免有 bug 或行为差异**
- 遇到问题请到 GitHub 提 issue（附 `latest.log` + 复现步骤）：
  https://github.com/bierangas26-cyber/dragonmaid-neoforge/issues
- 贴图 / 模型 / 动画 / 音效版权归原作者所有
- 如果原作者发布官方 NeoForge 版，请优先使用官方版本
