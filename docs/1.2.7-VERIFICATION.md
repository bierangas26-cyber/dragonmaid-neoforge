## 4. 未完成 / 降级 / 未验证（如实声明）

1. **客户端实机未验证**：本轮只跑了服务端/GameTest，没有启动 GL 客户端做截图对照。客户端侧仅做了静态校验（mixin 目标解析、注册接线、资源一致性）。首次客户端启动可能暴露渲染层问题。
2. **视觉降级**（client 工作包自述）：连续翼膜 RenderType 未接入实际渲染器、龙铠装饰网格未解析、人形龙武器姿态（IceFemaleModel 分支）与龙手武器渲染未搬、Iris/Oculus 兼容分支改为静默降级。
3. **附魔效果**：4 个附魔已能通过数据包注册（`effects: {}`，codec 接受），数值/查询/tooltip 逻辑在代码中；但 1.21.1 的 EnchantmentEffectComponents 级效果未逐项重建，实际数值是否与上游完全一致需游戏内实测。
4. **`DragonState#dragonmaid$setBladeMotion(int,int)` 未进接口**：DragonMixin 已有同名方法，战斗代码用反射兜底；动作起始帧可能丢失（minor，后续补 1 行接口声明即可）。
5. **有意的跳过**（均有字节码实证）：`PixieStealMixin`（IAF CE 2.2 原生已检查 `iceandfire:pixie_stolen_blacklist` 标签）、`FireEggModelMixin`（CE 2.2 `DragonEggModel#setupAnim` 已无 `isBurning` 调用）。
6. **开局伙伴 UI / 骑乘相机等客户端 mixin**：已按 1.21.1 重写，但无客户端实机验证。
7. **未发布**：GitHub 推送/release 未做（本轮网络访问 GitHub 受限）。
