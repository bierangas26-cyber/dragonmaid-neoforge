### 6.2 NeoForge 依赖下限放宽（GitHub issue #1）

- 背景：issue #1「前置需求」要求放宽 `neoforge 21.1.264+` 限制。
- 依据：硬依赖 IAF CE 2.2 自身声明 `neoforge [21.1.248,)`，因此 21.1.248 是本 mod 的现实下限。
- 改动：`META-INF/neoforge.mods.toml` 的 neoforge `versionRange` 由 `[21.1.264,)` 放宽为 `[21.1.248,)`。
- 实测：在 **NeoForge 21.1.248** 独立服务端（全新安装，1.21.1 + IAF CE 2.2 + GeckoLib 4.9.2 + Patchouli + Uranus/Jupiter + Architectury）启动：
  `Done (5.118s)!`、`DragonMaid: HELLO from server starting`，无 mixin/加载错误（仅 Jupiter 首启配置缺失与 AutoConfig @Pseudo 两类无关告警）。
- 结论：21.1.248+ 可运行；21.1.264 仍为开发编译目标。
