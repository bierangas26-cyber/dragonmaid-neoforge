## 已知限制（非阻塞）

- `HumanoidWater` 的 1.2 出水/水面逻辑暂保留 1.1 行为
- IAF CE 2.2 删除 `eatFoodBonus`，背包自动进食的「进食加成」钩子缺失（饥饿/回血/粒子/音效正常）
- 7 个 ForgeConfig* 客户端 mixin 目标第三方模组无 1.21.1 NeoForge 版，保持 @Pseudo 静默跳过（不影响 NeoForge 自带配置界面）
- 迷你化（仙灵之愿）/停肩飞行建议玩家实机体验确认（自动化测试环境难以稳定复现该 GUI 交互）

## 复现方式

```bash
# 编译 + GameTest（需要 JDK 21 与 NeoForge 21.1.264 moddev 环境）
gradle compileJava
gradle runGameTestServer

# 启动独立服务端 / 客户端
gradle runServer
gradle runClient
```
