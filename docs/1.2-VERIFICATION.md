## 上游一致性补齐（二轮审计，2026-11-08）

对上游 1.2.0-beta.4 jar 做全量类/资源比对（300 java + 446 assets/data），发现并修复：

| 项 | 说明 |
|---|---|
| 龙蛋性别 mixin ×3 | 补上 `FireDragonEggMixin` / `IceDragonEggMixin` / `LightningDragonEggMixin`（孵化性别由环境决定：火=灵魂火+维度、冰=霜凌/蓝冰、电=红石信号 1-7 雄 / 8-15 雌）；此前 port 只有 Jade 显示辅助，孵化逻辑未接 |
| `/dragonmaid get` archive | 补上 `RecallCommandArchive`：已收进号角/掉进虚空/石化的龙可以从召回账本查询 |
| 原版方块 tag 路径 | `data/minecraft/tags/blocks/*` → `data/minecraft/tags/block/*`（1.21.1 单数化，否则 `dragon_recall_altar` 不参与镐挖掘/工具等级判定） |
| 冰蛋性别判定 bug | `IceEggHatching` 原用普通冰（ICE），上游 1.2 为**蓝冰**（BLUE_ICE），已修正（Jade 显示同步受益） |

运行时验证（龙蛋性别，2026-11-08）：

| 蛋 | 条件 | 结果 |
|---|---|---|
| 火龙蛋 | 主世界 + 灵魂土/灵魂火 | **4/4 雄性**；对照组（无灵魂火）2 雄 2 雌随机 |
| 冰龙蛋 | 下方霜凌（dragon ice） | **3/3 雄性** |
| 冰龙蛋 | 下方蓝冰（blue ice） | **3/3 雌性** |
| 雷龙蛋 | 红石信号 15 | **3/3 雌性** |
| 雷龙蛋 | 红石信号 5 | **1/1 雄性** |

（对应 `FireDragonEggMixin` / `IceDragonEggMixin` / `LightningDragonEggMixin`，均在 IAF CE 2.2 实机孵化链路验证通过。）

召回账本归档查询（`RecallCommandArchive`）：实机用龙角收走一条已驯服龙后，`/dragonmaid get name` 立刻列出该龙，`/dragonmaid get all` 输出 `State: HORN, dragon, healthy (archive)` 及快照字段（维度/坐标/年龄/UUID 等）；此前测试中死亡或丢失的龙也以 `WORLD ... (archive)` 形式出现 ✅
资源比对结果：上游 446 个 assets/data 条目按 1.21 单数化映射后 **0 缺失、0 大小差异**。
## 已知限制（非阻塞）

- `HumanoidWater` 的 1.2 出水/水面逻辑暂保留 1.1 行为
- IAF CE 2.2 删除 `eatFoodBonus`，背包自动进食的「进食加成」钩子缺失（饥饿/回血/粒子/音效正常）
- 7 个 ForgeConfig* 客户端 mixin 目标第三方模组无 1.21.1 NeoForge 版，保持 @Pseudo 静默跳过（不影响 NeoForge 自带配置界面）
- 迷你化（仙灵之愿）/停肩飞行建议玩家实机体验确认（自动化测试环境难以稳定复现该 GUI 交互）
